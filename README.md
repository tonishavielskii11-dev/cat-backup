# Cat Backup — резервное копирование котиков на Яндекс.Диск



Курсовая работа: программа получает картинки кошек с текстом

с сайта [cataas.com](https://cataas.com) и загружает их

на Яндекс.Диск через REST API.



## Возможности



- Получение картинок кошек с произвольным текстом через API cataas.com

- Создание папки на Яндекс.Диске с именем группы

- Загрузка картинок «по воздуху» — без сохранения на локальный диск

- Прогресс-бар во время загрузки

- Сохранение отчёта о загруженных файлах в `results.json`



## Требования



- Python 3.8+

- Аккаунт Яндекс.Диска

- OAuth-токен с [Яндекс.Полигона](https://yandex.ru/dev/disk/poligon/)
